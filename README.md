# React Projects Showcase

A collection of interactive React components and mini-projects built with React 19 and Vite.

## Projects Included

- **Task Manager / To-Do App (`src/todo`)**: Interactive form allowing you to type tasks and see them immediately in a live list, with individual task deletion, clear actions, and custom styling.
- **Campus App (`src/campus`)**: Student selector, profile overview, attendance tracker, and study task manager.
- **Student Cards & Challenges (`src/cards`)**: Modular student profile cards and interactive layout exercises.
- **State Practice (`src/practice`)**: React component state demonstrations and attendance counter logic.

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run the development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
